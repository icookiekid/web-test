🔀 상단 메뉴 순서 변경

아래 목록에서 위/아래 버튼을 누르면 상단 메뉴 순서가 바로 바뀝니다. PC에서는 항목을 잡고 끌어서 옮기는 것도 가능합니다.
변경 내용은 이 브라우저에 자동 저장됩니다. 다른 기기에도 적용하려면 ☁️ 동기화 → Firebase에 저장을 눌러주세요.

초보자 안내: 이 기능은 HTML 코드를 직접 수정하지 않아도 메뉴 순서를 바꿀 수 있게 만든 기능입니다. 저장되는 값은 webtest_nav_order이며, Firebase 저장 경로는 기존과 똑같이 users / UID / sites / web-test를 유지합니다.
