STEP 02
Python 3.9.x 32bit 설치
🔴
반드시 32bit! OS가 64bit여도 Python은 32bit
키움 OpenAPI+는 32bit COM 컴포넌트 — Python 64bit 설치 시 완전히 작동 안 함
다운로드 URL
https://www.python.org/downloads/windows/
Python 3.9.x → Files 섹션:
✅ Windows installer (32-bit)   ← 이것만!
❌ Windows installer (64-bit)   ← 절대 금지
설치 경로: C:\Python39_32\   ← 이름 구분 권장
☑ Add Python 3.9 to PATH  ← 반드시 체크
검증 — 반드시 32 출력되어야 함
C:\> C:\Python39_32\python.exe -c "import struct; print(struct.calcsize('P')*8)"
32 ← 32면 정상. 64면 재설치!

CONFIG 핵심 설정
초보자 권장 설정
CONFIG = {
    "total_budget":       1_000_000,  # ★ 처음엔 100만원
    "max_stocks":         3,           # ★ 처음엔 3종목
    "scalp_tp":           0.025,       # 단타 익절 +2.5%
    "scalp_sl":           0.015,       # 단타 손절 -1.5%
    "scalp_budget_pct":   0.10,        # 단타 종목당 10%
    "swing_budget_pct":   0.15,        # 스윙 종목당 15%
    "daily_loss_limit":   -0.02,       # ★ 처음엔 -2% (절대 완화 금지)
    "consec_loss_pause":  2,           # 연속 손절 2회 시 30분 중단
}
파라미터기본값의미주의
total_budget10,000,000운용 총 자금처음엔 100만원
scalp_budget_pct0.15단타 종목당 비중0.10~0.20 권장
swing_budget_pct0.20스윙 종목당 비중0.15~0.25 권장
daily_loss_limit-0.03일일 손실 한도절대 완화 금지!
scalp_tp0.025단타 익절 +2.5%반드시 sl보다 크게
scalp_sl0.015단타 손절 -1.5%반드시 tp보다 작게
STEP 11
자금 배분 구조 — 여러 종목 분산 매수
🎯
한 종목에 전부 투자하지 않습니다
scalp_budget_pct(15%) × 운용총액 = 종목당 투자금액
1,000만원 × 15% = 한 종목 최대 150만원
1,000만원 × 20% = 스윙 한 종목 최대 200만원
수량 계산식
수량 = int( min(잔고, 운용총액) × budget_pct / 현재가 )
예: 잔고 10,000,000원 / scalp_budget_pct=0.15 / 삼성전자 81,000원
→ int(10,000,000 × 0.15 / 81,000) = int(18.5) = 18주 매수 (약 145.8만원)
1,000만원 기준 최대 운용 시나리오 (단타3 + 스윙2)
단타 종목A (15%)150만원
단타 종목B (15%)150만원
단타 종목C (15%)150만원
스윙 종목D (20%)200만원
스윙 종목E (20%)200만원
현금 버퍼 (15%)150만원
총 운용: 850만원 (85%) / 현금버퍼: 150만원 (15%)
