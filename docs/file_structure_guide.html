1. 왜 파일을 나눴나요?

처음에는 GitHub에 index.html 하나만 올리면 되도록 모든 내용을 한 파일 안에 넣었습니다. 하지만 코드 한 줄 해설, Firebase 문서, 자동매매 매뉴얼까지 모두 들어가면서 파일이 커졌고, 모바일에서 문서를 클릭할 때 로딩이 느려졌습니다.

기존 단일 구조
올릴 파일은 하나라서 편하지만, 모든 문서를 한 번에 품고 있어서 모바일이 무거워집니다.
현재 분리 구조
메인 화면은 index.html이 담당하고, 큰 문서는 docs 폴더에서 필요할 때만 열립니다.
Firebase 저장 경로는 계속 유지합니다. users / 로그인한 사용자 UID / sites / web-test

중요한 점은 문서 파일을 분리해도 Firebase 데이터 저장 위치는 바뀌지 않는다는 것입니다. 기존 블로그의 blogData 경로와 섞지 않습니다.

2. 현재 폴더 구조

GitHub의 web-test 폴더 안은 아래처럼 구성되어야 합니다.

web-test/ ├─ index.html └─ docs/ ├─ file_structure_guide.html ├─ index_code_guide.html ├─ firebase_guide.html ├─ firebase_function.html ├─ change_ver18.html ├─ auto_trade_v1_index.html ├─ auto_trade_v1_01.html ├─ auto_trade_v1_02.html ├─ auto_trade_v1_03.html ├─ auto_trade_v1_04.html ├─ auto_trade_v1_05.html ├─ auto_trade_v1_06.html ├─ auto_trade_v1_07.html ├─ auto_trade_v1_08.html ├─ auto_trade_v1_09.html ├─ auto_trade_v1_10.html ├─ auto_trade_v1_11.html ├─ auto_trade_v1_12.html └─ auto_trade_v2_ready.html
주의: docs 폴더 이름을 바꾸면 문서 링크가 깨질 수 있습니다. Docs, doc, 문서처럼 바꾸지 말고 반드시 docs 그대로 두는 것이 안전합니다.

4. GitHub 업로드 방법

  1. 다운로드한 ZIP 파일을 먼저 압축 해제합니다.
  2. GitHub에서 icookiekid.github.io 저장소로 들어갑니다.
  3. web-test 폴더를 엽니다.
  4. index.html 파일을 업로드합니다.
  5. docs 폴더 전체도 같이 업로드합니다.
  6. 화면에서 web-test/index.html과 web-test/docs/... 파일들이 보이면 정상입니다.
이번 구조에서는 index.html만 올리면 문서가 일부 열리지 않을 수 있습니다. 반드시 docs 폴더 전체를 함께 올려야 합니다.

5. 나중에 수정할 때 기준

메인 화면, 메뉴, Firebase 저장 기능을 고칠 때

index.html을 수정합니다. 로그인, 동기화, 메모, 가계부, 블로그 저장 기능은 메인 파일에 있습니다.

문서 내용만 고칠 때

docs 폴더 안의 해당 문서 파일만 수정하면 됩니다. 예를 들어 Firebase 설명만 고치려면 docs/firebase_guide.html을 수정하면 됩니다.

새 문서를 추가할 때

  1. docs/새문서파일.html을 만듭니다.
  2. index.html의 문서 보관함 메뉴에 새 버튼을 추가합니다.
  3. 버튼 링크를 docs/새문서파일.html로 연결합니다.
<button onclick="location.href='docs/새문서파일.html'"> 새 문서 열기 </button>

6. 오류가 날 때 확인할 것

문서를 눌렀는데 404 또는 Not Found가 나올 때

  • docs 폴더가 GitHub web-test 안에 있는지 확인합니다.
  • 파일명이 링크와 정확히 같은지 확인합니다. 대문자/소문자도 다르게 취급될 수 있습니다.
  • 파일을 web-test/docs가 아니라 저장소 맨 위나 다른 폴더에 올리지 않았는지 확인합니다.

수정했는데 예전 화면이 보일 때

  • PC에서는 Ctrl + F5로 강력 새로고침합니다.
  • 모바일에서는 브라우저 탭을 닫고 다시 열거나, 방문 기록/캐시를 지운 뒤 확인합니다.
