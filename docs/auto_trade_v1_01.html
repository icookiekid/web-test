⚙️ 설치 요구사항

🖥️ 시스템 환경

  • Windows 10/11 (64bit OS)
  • Python 3.9.x — 반드시 32bit 버전
  • 키움증권 계좌 (모의투자 가능)
  • 키움 OpenAPI+ 설치 완료
  • 영웅문 HTS 조건검색식 5개 저장

📦 Python 패키지

  • PyQt5 == 5.15.9
  • pandas == 2.0.3
  • numpy == 1.24.4
  • matplotlib (백테스트 차트용)
  • yfinance (데이터 1순위)
  • finance-datareader (데이터 2순위)
  • pykrx (데이터 3순위)
패키지 한 번에 설치
# Python 3.9 32bit 환경에서 실행 pip install PyQt5==5.15.9 pandas==2.0.3 numpy==1.24.4 ^ matplotlib yfinance finance-datareader pykrx
⚠️
32bit Python 필수
키움 OpenAPI+는 32bit 전용 DLL입니다. 64bit Python에서는 QAxWidget 로드 시 오류가 발생합니다. python.org에서 Windows x86 executable installer를 설치하세요.
💡
백테스트만 사용할 경우
OpenAPI 설치 없이도 백테스트 기능은 완전히 동작합니다. 64bit Python에서 명령줄로 v1_backtest_20260427.py를 직접 실행하거나, 통합 파일에서 PyQt5 없이 백테스트 클래스만 import 할 수 있습니다.

💡 매매 전략 상세

🟢 단타 전략 (ScalpStrategy)

  • 조건검색 결과 + RSI 과매도 확인
  • 거래량 2배 이상 급증 확인
  • VWAP 지지 여부 체크
  • 종목당 자금의 15% 투입
  • 익절 +2.5% / 손절 -1.5%
  • 손절 후 30분 동일 종목 재진입 금지
  • RSI 65 이상 + 수익 시 추가 청산

🔵 스윙 전략 (SwingStrategy)

  • MA20 > MA60 정배열 확인
  • MACD 히스토그램 골든크로스
  • 볼린저밴드 중심선 위 확인
  • 종목당 자금의 20% 투입
  • 익절 +10% / 손절 -5%
  • 최대 보유 10영업일
  • MA20 이탈 시 자동 청산

📊 백테스트 엔진 개요

일봉(OHLCV) 데이터를 사용한 단타·스윙 전략 시뮬레이션 엔진입니다. Look-ahead bias를 완전 차단하여 신뢰성 있는 검증을 제공합니다.

📡
데이터 자동 폴백
yfinance → FinanceDataReader → pykrx → CSV 순서로 자동 시도. 성공 데이터는 캐시 저장
🚫
Look-ahead Bias 차단
전날 지표로 신호 판단, 당일 시가로 매수. 미래 데이터를 참조하지 않음
💸
실제 거래 비용 반영
수수료 0.015%, 거래세 0.20%, 슬리피지 0.05% 적용
🔄
Walk-Forward 검증
전체 기간을 5구간으로 나눠 오버피팅 방지 검증

백테스트 시뮬레이션 방식 (단타)

전날 RSI·거래량으로
매수 신호 판단
→
당일 시가 + 슬리피지로 매수
→
당일 고가 ≥ 익절가 → 익절
/
당일 저가 ≤ 손절가 → 손절

고가·저가 동시 도달(갭이 큰 날) → 보수적으로 손절 처리 | 미청산 → 당일 종가로 시간청산

Walk-Forward 검증 해석
5개 구간 모두에서 승률이 유사하게 유지되면 오버피팅 가능성이 낮습니다. 특정 구간에서만 좋은 결과가 나왔다면 해당 기간에만 맞춰진 전략일 수 있습니다.

🔬 파라미터 최적화 (그리드 서치)

단타 전략의 주요 파라미터를 자동으로 탐색하여 최적 조합을 찾습니다.

최적화 대상 파라미터 그리드
GRID = { "scalp_rsi_buy": [30, 33, 35, 38, 40], # 5가지 "scalp_tp": [0.020, 0.025, 0.030, 0.035], # 4가지 "scalp_sl": [0.010, 0.012, 0.015, 0.018], # 4가지 "scalp_vol_ratio": [1.5, 2.0, 2.5], # 3가지 } # 총 조합: 5 × 4 × 4 × 3 = 240가지 (tp > sl 조건 필터링 후 ~180가지)

최적화 점수 산식

score = (승률/100) × 손익비 / (|MDD|/10) × max(샤프, 0.1)

점수가 높을수록 수익성, 안정성, 위험 대비 효율이 모두 좋은 파라미터입니다. 결과는 backtest_results/bt_optimize_코드.csv에 저장됩니다.

⚠️
최적화 결과 과신 주의
최적화된 파라미터는 과거 데이터에 맞춰진 것입니다. 반드시 Walk-Forward 검증으로 미래 성과도 확인 후 사용하세요. Top 1보다는 Top 3~5의 평균적인 파라미터를 채택하는 것이 더 안정적입니다.

📦 EXE 실행파일 빌드

1
build_exe.bat 실행
프로젝트 폴더에서 build_exe.bat를 더블클릭합니다. 반드시 32bit Python 3.9 환경이어야 합니다.
2
자동 빌드 (약 3~5분)
패키지 설치 → PyInstaller 실행 → 단일 EXE 생성 → 임시 파일 정리 순으로 진행됩니다.
3
결과물 확인
dist/키움자동매매_백테스트_v1.exe 파일이 생성됩니다. 이 파일만 배포하면 됩니다.

✅ EXE 빌드 주의사항

  • 32bit Python 3.9 환경에서 빌드
  • 키움 OpenAPI+ 설치된 PC에서 빌드
  • 아이콘: kiwoom.ico를 같은 폴더에 두면 자동 적용
  • 빌드 오류 시 build/warn*.txt 확인

📌 EXE 실행 환경

  • 키움 OpenAPI+ 설치된 PC 필요
  • 백테스트 기능은 OpenAPI 없이도 동작
  • antivirus 오탐 가능 → 예외 등록 필요
  • 로그 파일은 EXE 위치에 생성됨
SUPPORT

❓ 자주 묻는 질문

Q. 조건검색식이 로드되지 않습니다

영웅문에 저장된 조건검색식 이름이 CONDITION_NAMES와 정확히 일치해야 합니다. 띄어쓰기·대소문자·특수문자를 포함해 완전히 동일해야 합니다. 📋 조건검색식 목록 버튼으로 현재 로드된 목록을 확인하세요.

Q. 백테스트에서 "데이터 없음"이 나옵니다

yfinance, FinanceDataReader, pykrx 모두 실패한 경우입니다. 인터넷 연결을 확인하고 --clear-cache 옵션으로 재시도하세요. 지속 실패 시 HTS에서 CSV를 직접 내보내어 backtest_data/에 넣고 --source csv로 실행하세요.

Q. PyQt5 import 오류가 발생합니다

64bit Python에서는 키움 OpenAPI+ DLL을 로드할 수 없습니다. 32bit Python 3.9를 별도 설치하거나, 백테스트만 사용할 경우 64bit 환경에서 v1_backtest_20260427.py를 직접 실행하세요.

Q. 빌드한 EXE에서 바이러스 경고가 뜹니다

PyInstaller로 패키징한 EXE는 일부 백신에서 오탐이 발생합니다. Windows Defender 또는 사용 중인 백신에서 해당 파일을 예외 등록하거나, 서명 인증서를 적용하면 해결됩니다.

Q. 캐시를 초기화하려면?

# 방법 1: 명령줄 python v1_backtest_20260427.py --clear-cache # 방법 2: 폴더 직접 삭제 backtest_cache/ 폴더 삭제

Q. 매매 로그는 어디서 확인하나요?

실행 폴더의 log_standard_날짜.txt 파일에 저장됩니다. GUI 내 로그 창에도 실시간으로 표시됩니다.
