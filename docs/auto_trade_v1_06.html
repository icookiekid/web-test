SECTION 04
TRRateLimiter · OHLCVCache · calc_business_days
TRRateLimiter (250ms)
키움 초당 5회 제한. 250ms=초당 4회. sleep 없이 allow()==False면 요청 스킵. 이벤트루프 블로킹 없음.
OHLCVCache (5분 TTL)
5초마다 청산체크가 매번 TR 요청하면 한도 초과. 5분 캐시로 TR 절약. 매도 후 invalidate()로 삭제.
calc_business_days ★수정⑤
int(days×5/7) 근사값 대신 HOLIDAYS_KR 참조해 정확한 영업일 계산. 공휴일 많은 주에 오차 없음.

SECTION 09
_run_ai() — 비동기 스레드 실행
공통 AI 스레드 (★수정⑥: 중복 제거)
def _run_ai(fn):
    result = [None]
    def w(): result[0] = fn()
    t = threading.Thread(target=w, daemon=True)
    t.start(); t.join(timeout=30)  # 최대 30초
    return result[0]
# daemon=True: 메인스레드 종료 시 함께 종료
# result=[None]: 클로저 변수 공유 패턴
# timeout=30: 서버 무응답 시 영구 대기 방지

저항선 돌파 = 매수세 > 매도세. h.iloc[-6:-1].max()
