⚙️ Firebase 함수 사용법

로그인, 저장, 불러오기 함수가 어떤 순서로 움직이는지 쉽게 정리했습니다.

전체 흐름

1. 로그인

사용자가 Firebase 이메일과 비밀번호를 입력하면 Firebase Authentication이 사용자를 확인합니다.

2. UID 확인

로그인에 성공하면 Firebase가 사용자마다 고유한 UID를 알려줍니다.

3. 저장 경로 생성

코드는 users / UID / sites / web-test 위치를 지정합니다.

4. 저장·불러오기

글, 메모, 가계부, 메뉴 순서 같은 브라우저 데이터를 payload로 저장하고 다시 불러옵니다.

로그인 함수

window.firebaseLogin(email, password) 함수는 이메일과 비밀번호를 Firebase에 보내 로그인합니다. 성공하면 현재 사용자 정보가 생기고, 실패하면 오류 메시지를 보여줍니다.

회원가입 함수

window.firebaseSignUp(email, password) 함수는 새 계정을 만듭니다. Firebase Email/Password 방식은 비밀번호가 6자 이상이어야 합니다.

저장 함수

window.firebaseSaveAllLocalData(payload) 함수는 현재 브라우저의 데이터를 Firestore에 저장합니다.

const docRef = doc(db, 'users', user.uid, 'sites', 'web-test');

위 한 줄이 가장 중요합니다. 이 줄 때문에 저장 위치가 기존 블로그가 아니라 web-test 전용 문서가 됩니다.

불러오기 함수

window.firebaseLoadAllLocalData() 함수는 같은 위치에서 데이터를 가져옵니다. 저장 위치와 불러오기 위치가 같아야 다른 기기에서도 같은 자료가 보입니다.

문제가 생겼을 때 확인 순서

  1. 상단 ☁️ 동기화에서 로그인 상태인지 확인합니다.
  2. Firebase 콘솔에서 Authorized domains에 icookiekid.github.io가 있는지 확인합니다.
  3. Firestore Rules가 users/{userId}/{document=**} 구조를 허용하는지 확인합니다.
  4. Firestore 실제 문서 위치가 users / 내 UID / sites / web-test인지 확인합니다.
